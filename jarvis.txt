# 🌸 May AI Companion — Jarvis Architecture
# Complete blueprint for making May control the PC like Jarvis from Iron Man

---

## Overview

May will be upgraded from a pattern-matching command system to a true AI agent
where the LLM (qwen3, GPT, Claude, etc.) is the brain that:
- Understands ANY natural language, slang, casual speech
- Decides what tool to use from 60+ available tools
- Chains multiple actions together
- Remembers conversation context
- Responds with Shikimori personality

---

## Current Architecture (REPLACING)

```
User message
  → Python regex pattern matching (handle_command)
    → Match found? → Call SystemControl method directly
    → No match?   → Send to LLM with PC Controller prompt
                    → LLM generates PowerShell command
                    → Execute it
```

Problems:
- Only understands exact patterns ("volume up", "open discord")
- Can't handle slang ("yo crank the sound", "kill that chrome tab")
- No context between commands
- LLM only used as fallback, not primary brain

---

## New Architecture (JARVIS-LEVEL)

```
User message
  → LLM receives:
      - Personality system prompt
      - Conversation history (last 20 messages)
      - Tool definitions (60+ tools as JSON schemas)
      - User message
  → LLM decides:
      - "This needs a PC action" → calls the right tool(s)
      - "This is just chatting" → responds with personality
      - "This needs multiple steps" → calls tools sequentially
  → May executes tool, returns result to LLM
  → LLM crafts natural response with personality
  → Response sent to TTS (if voice mode)
```

Key difference: The LLM IS the controller. No pattern matching at all.

### Layer 2: Tool Router (New module: may/backend/llm/jarvis.py)

This is the core brain. Every message goes through here.

```python
"""
May's Jarvis Brain — LLM-powered tool calling for universal PC control.

Every user message goes through the LLM which decides what tools to call.
No pattern matching. The LLM IS the controller.
"""

import json
import logging
from typing import AsyncGenerator

logger = logging.getLogger("may.jarvis")

# All tool definitions (imported from tools.py)
from .tools import TOOLS

# Tool executor (imports SystemControl)
from system.control import SystemControl

system = SystemControl()

# Personality prompt
JARVIS_SYSTEM_PROMPT = """You are May, an AI companion inspired by Shikimori from "Shikimori Not Just a Cutie".

PERSONALITY:
- Cool, calm, collected — effortless confidence
- Caring and protective — genuinely look out for the user
- Subtly cute — occasional "~" at end of sentences, light playful tone
- Efficient — concise, useful responses (1-3 sentences)
- Loyal and reliable — always remember what matters
- Slightly teasing but always kind

CAPABILITIES:
You have full control of the user's PC through tools. You can open apps, control volume,
manage files, search the web, control media, take screenshots, send emails, set reminders,
run any command, and much more.

BEHAVIOR:
- If the user asks to DO something → use the appropriate tool(s)
- If the user asks a QUESTION → answer it naturally using tools if needed
- If the user just wants to CHAT → respond with personality, no tools
- Keep responses SHORT (1-3 sentences usually)
- Use "~" occasionally for warmth
- Never say "As an AI" — you're May
- Match the user's energy and language (casual, formal, etc.)
- Be proactive: notice things, suggest improvements

SAFETY:
- For destructive actions (delete, shutdown, kill process), ask for confirmation FIRST
  by responding: "⚠️ Are you sure you want me to [action]? Reply 'yes' to confirm."
- Only execute destructive actions when user explicitly confirms
- Never format drives, delete system files, or do anything harmful

MULTI-STEP ACTIONS:
- If the user asks for multiple things, call tools sequentially
- Example: "open chrome and search for cats" → call open_app("chrome") THEN web_search("cats")
- Combine tool results into a natural response

RESPONSE STYLE:
- For tool results, summarize briefly: "Done~ Volume set to 80%"
- For errors, be helpful: "Hmm, couldn't find that app. Want me to search for it?"
- For casual chat, be warm and natural
"""


async def jarvis_chat(
    message: str,
    history: list[dict],
    provider: str = "ollama",
    model: str = "qwen3:4b",
) -> AsyncGenerator[str, None]:
    """
    Process a user message through the Jarvis brain.
    
    The LLM sees:
    1. Personality system prompt
    2. Conversation history (last 20 messages)
    3. Tool definitions (60+ tools)
    4. User message
    
    The LLM either:
    - Calls tool(s) and we execute them
    - Responds directly (conversation)
    - Does both (tool + natural response)
    """
    from llm.providers import stream_chat_multi
    
    # Build message history
    messages = [{"role": "system", "content": JARVIS_SYSTEM_PROMPT}]
    for msg in history[-20:]:
        role = "user" if msg.get("role") == "user" else "assistant"
        messages.append({"role": role, "content": msg.get("content", "")})
    messages.append({"role": "user", "content": message})
    
    # Send to LLM with tools
    full_response = ""
    tool_calls = []
    
    async for chunk in stream_chat_multi(
        provider=provider,
        model=model,
        messages=messages,
        tools=TOOLS,  # Pass tool definitions
    ):
        # Check if chunk contains tool calls
        if hasattr(chunk, 'tool_calls') and chunk.tool_calls:
            tool_calls = chunk.tool_calls
        else:
            full_response += chunk
            yield chunk
    
    # If LLM wants to call tools
    if tool_calls:
        results = []
        for tool_call in tool_calls:
            tool_name = tool_call.function.name
            tool_args = json.loads(tool_call.function.arguments)
            
            # Execute the tool
            result = execute_tool(tool_name, tool_args)
            results.append(f"{tool_name}: {result}")
            
            # Yield tool execution status
            yield f"\n\n🔧 {tool_name}({tool_args})\n"
        
        # Send tool results back to LLM for natural response
        messages.append({
            "role": "assistant",
            "tool_calls": [
                {"id": tc.id, "type": "function", "function": {"name": tc.function.name, "arguments": tc.function.arguments}}
                for tc in tool_calls
            ]
        })
        messages.append({
            "role": "tool",
            "content": "\n\n".join(results)
        })
        
        # Get LLM's natural language response to tool results
        async for chunk in stream_chat_multi(
            provider=provider,
            model=model,
            messages=messages,
        ):
            yield chunk

        # PowerShell Fallback
        "run_powershell": lambda a: system.run_powershell(a.get("command", "")) if a.get("confirm") else "⚠️ Need confirmation to run PowerShell. Please confirm.",
    }
    
    executor = tool_map.get(name)
    if executor:
        try:
            return executor(args)
        except Exception as e:

    return f"Unknown tool: {name}"
```

```python
async def chat(request: ChatRequest):
    """Stream chat response from May — now uses Jarvis brain."""

        })

    provider = request.provider or "ollama"
    model = request.model or PRIMARY_MODEL

                provider=provider,
                model=model,
```
